# iOS 原生应用竖屏 UI 设计文档

本文档描述 EmbyTok iOS 原生应用竖屏模式下的 UI 设计规范。

---

## 一、纯净模式 vs 普通模式对比

### 按钮布局

| 元素 | 普通模式 | 纯净模式 |
|------|----------|----------|
| **标题** | ✅ 显示 | ❌ 隐藏 |
| **右侧浮动按钮组** | ✅ 显示 | ❌ 隐藏 |
| **底部进度条控制栏** | ✅ 显示 | ✅ 显示（点击可切换显隐） |
| **纯净模式切换按钮** | 底部右侧 (`eye.slash` 图标) | 底部右侧 (`eye` 图标) |
| **状态栏** | ✅ 显示 | ❌ 隐藏 |
| **导航栏** | ✅ 显示 | ❌ 隐藏 |

### 右侧浮动按钮组（普通模式）

从上到下依次排列：

1. **缓存按钮** + 缓存大小标签
   - 图标: `arrow.down.circle`
   - 已缓存: `checkmark.circle.fill` (绿色)
   - 缓存中: `arrow.triangle.2.circlepath.circle.fill` (黄色)
   
2. **收藏按钮**
   - 图标: `heart` / `heart.fill`
   - 已收藏: 粉色填充心形
   
3. **静音按钮**
   - 图标: `speaker.slash` (静音) / `speaker.wave.2` (有声音)
   
4. **旋转按钮**
   - 图标: `rotate.right`
   - 功能: 每次点击旋转 90°
   
5. **随机播放**
   - 图标: `shuffle`

## 二、导航栏功能（仅普通模式）

### 导航栏左侧按钮

**菜单按钮** (`line.3.horizontal`)

点击后弹出操作菜单：

| 选项 | 功能 |
|------|------|
| 查看收藏 | 打开收藏列表页面，显示已收藏的视频 |
| 设置 | 打开设置页面 |
| 全部视频 | 打开视频网格页面 |
| 随机播放 | 随机跳转到列表中的任意视频 |
| 随机收藏 | 随机跳转到收藏列表中的视频（仅在有收藏时显示） |

### 导航栏右侧按钮

从右到左排列：

1. **信息按钮** (`info.circle`)
   - 打开当前视频的信息页面（Sheet 形式）
   - 显示内容：
     - 文件名称（可编辑，仅 Folder 服务支持改名）
     - 收藏开关
     - 文件路径
     - 文件大小

2. **网格按钮** (`square.grid.2x2`)
   - 打开全部视频网格页面
   - 支持切换显示模式

## 三、全部视频页面

### 显示模式切换

页面右上角提供分段控制器，可切换两种显示模式：

| 模式 | 说明 |
|------|------|
| **卡片模式** (默认) | 网格布局，显示缩略图和标题，自动适配列数 |
| **列表模式** | 单列布局，显示缩略图、标题、时长和大小 |

### 卡片模式

```
┌─────────┐  ┌─────────┐  ┌─────────┐
│         │  │         │  │         │
│ 缩略图  │  │ 缩略图  │  │ 缩略图  │
│         │  │         │  │         │
├─────────┤  ├─────────┤  ├─────────┤
│ 标题    │  │ 标题    │  │ 标题    │
└─────────┘  └─────────┘  └─────────┘
```

- 列数自动适配：
  - iPhone: 2-4 列
  - iPad: 2-6 列
- 单元格宽高比: 1 : 1.6
- 间距: 8pt
- 圆角: 10pt

### 列表模式

```
┌────────────────────────────────────────────┐
│ ┌──────────┐  视频标题                     │
│ │          │  12:34  ·  256 MB            │
│ │  缩略图   │                              │
│ └──────────┘                               │
└────────────────────────────────────────────┘
```

- 缩略图固定宽度: 132pt
- 行高: 92pt
- 显示元数据: 时长 + 文件大小

### 交互

- 点击视频: 返回视频流并跳转到对应视频
- 滚动到底部: 自动加载更多视频
- 模式切换: 0.2 秒交叉淡入淡出动画

## 四、视频信息页面

以 Sheet 形式弹出，包含以下功能：

### 改名功能

| 项目 | 说明 |
|------|------|
| 适用服务 | 仅 Folder 服务支持 |
| 操作 | 修改名称后点击"保存名称" |
| 反馈 | 成功时震动 + 更新显示；失败时弹窗提示 |

### 收藏开关

- 一键切换当前视频的收藏状态
- 状态同步到视频流中的收藏图标

### 详情信息

| 字段 | 说明 |
|------|------|
| 路径 | 视频文件的相对路径 |
| 大小 | 视频文件大小（自动获取） |

## 五、手势操作

### 基础手势（可配置开关）

| 手势 | 功能 | 默认启用 |
|------|------|----------|
| **双指捏合张开** (scale ≥ 1.1) | 进入纯净模式 | ✅ |
| **双指捏合收拢** (scale ≤ 0.9) | 退出纯净模式 | ✅ |
| **双指单击/双击** | 切换静音 | ✅ |

### 纯净模式专属手势

| 手势 | 功能 | 默认状态 |
|------|------|----------|
| **单指左右滑动** | 调节播放进度 | ❌ 默认关闭（需手动开启） |

**滑动进度调节参数：**
- 步进值: 可配置 5-120 秒（默认 10 秒）
- 计算方式: 每滑动约 100pt 调整对应秒数

### 其他交互

| 操作 | 功能 |
|------|------|
| **单击屏幕** | 播放/暂停 + 显示控制栏 |
| **进度条拖动** | 精确调节播放位置 |

## 三、进度条设计

### 控制栏布局

```
┌─────────────────────────────────────────────────────────┐
│  [00:42] ═════════════●════════════════  [05:30]       │
│   当前时间            滑动条              总时长/剩余时间  │
└─────────────────────────────────────────────────────────┘
```

### 样式参数

| 属性 | 值 |
|------|-----|
| 容器背景 | 黑色半透明 (`alpha: 0.25`) |
| 容器圆角 | 14pt |
| 时间标签字体 | 等宽数字字体，12pt |
| 时间标签颜色 | 白色 |
| 已播放轨道颜色 | 白色 90% 不透明度 |
| 未播放轨道颜色 | 白色 25% 不透明度 |
| 滑块颜色 | 白色 90% 不透明度 |

### 时间显示模式

| 模式 | 左侧显示 | 右侧显示 |
|------|----------|----------|
| `elapsed` (默认) | 已播放时间 | 总时长 |
| `remaining` | 剩余时间 (带 `-` 前缀) | 总时长 |

### 交互行为

1. **触摸开始**: 记录当前播放状态
2. **拖动中**: 实时更新时间和标签
3. **触摸结束**: 跳转到目标位置，恢复之前的播放状态
4. **自动隐藏**:
   - 普通模式: 不自动隐藏
   - 纯净模式: **8 秒后自动隐藏**

## 六、提示视图

### 静音提示 (MuteHint)

- 位置: 静音按钮左侧
- 内容: "已静音" / "已开启声音"
- 背景: 黑色半透明 (`alpha: 0.6`)，圆角 10pt
- 自动消失: 3 秒后

### 进度调节提示 (SeekHint)

- 位置: 控制栏下方居中
- 格式: `当前时间 / 总时长` 或 `-剩余时间 / 总时长`
- 背景: 黑色半透明 (`alpha: 0.6`)，圆角 12pt
- 自动消失: 3 秒后

## 七、手势设置入口

在 **设置 > 手势控制** 页面可配置：

### 基础手势

| 设置项 | 说明 |
|--------|------|
| 双指捏合切换纯净模式 | 双指张开进入，捏合退出 |
| 双指点击切换静音 | 单击或双击均触发 |

### 纯净模式

| 设置项 | 说明 |
|--------|------|
| 左右滑动调节进度 | 仅在纯净模式下生效 |
| 滑动步进 | 每滑动约 100pt 调整的秒数（5-120秒） |

---

## 八、视觉反馈

- **触觉反馈**: 所有按钮点击和手势操作都有轻微震动反馈
- **动画**: 控制栏显隐使用 0.2 秒淡入淡出动画
- **图标切换**: 状态变化时图标即时更新
